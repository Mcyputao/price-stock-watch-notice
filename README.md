# 价格补货盯梢 · 公告

这是桌面软件「价格补货盯梢」打开后读取的公告文件。修改 `announcement.json` 并推送到 `main` 后，用户下次打开软件或点「刷新」即可看到，不必重新安装。

字段说明：

- `title`：公告标题
- `body`：正文（可换行）
- `latest_version`：当前应使用的版本。高于用户本机版本时，软件会提示「请重新下载」
- `download_url`：可选，https 下载地址，会显示为「重新下载最新版」
- `links`：可选，其他产品或网站，格式 `{"text": "显示名", "url": "https://..."}`，只接受 https
